# Academic Bridges & University Lab Companions

[Tutorials Hub](../README.md) • Academic Bridges

Welcome to the **Academic Bridges** track of `HyperV-LinuxLab`.

This section provides dedicated lab alignment companions for university computer science and systems administration coursework. These companions map university curricula 1:1 to local Hyper-V execution, allowing students to complete hands-on labs without cloud infrastructure expenses, resource limits, or proprietary platform dependencies.

---

## Available Course Bridges

### 1. [UVA IT 3140: DevSecOps & Cloud Operations](uva-it3140/README.md)
*University of Virginia - Department of Engineering and Applied Science*
- **Module Coverage**: Linux System Administration (Labs 1–8), OpenTofu Infrastructure as Code, Python Flask Microservices, CI/CD pipelines.
- **Enterprise Distros**: AlmaLinux 9 (RHEL) & Ubuntu 24.04 LTS.
- **Features**: Complete local lab runbooks, academic review questions with deep systems engineering explanations, and multi-tier service deployments.
